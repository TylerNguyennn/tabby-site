How to save all open tabs in Chrome

The quickest way: press Ctrl+Shift+D (⌘+Shift+D on a Mac). Chrome bookmarks every tab in the window into one new folder. If you want to close the tabs and find them again easily, save them to a tab manager instead. Here are three ways, from built-in to best.

By Nguyen Huu Tai, maker of Tabby · Updated October 19, 2026

1. Bookmark all tabs (built into Chrome)

  1. Press Ctrl+Shift+D (Windows, Linux, ChromeOS) or ⌘+Shift+D (Mac). You can also open the ⋮ menu → Bookmarks and lists → Bookmark all tabs.
  2. Name the folder and click Save.
  3. To reopen them, right-click the folder in the bookmarks bar or Bookmark manager and choose Open all.

Good for: a one-off save. Downside: each save adds another bookmarks folder, and they pile up fast.

2. Save a tab group (built into Chrome)

If your tabs are in a tab group, Chrome saves the group for you: close the group and it stays in the bookmarks bar (or the Tab groups menu), ready to reopen. Downside: it only works for tabs you grouped first, and saved groups crowd the bar.

3. Save the window to a collection with Tabby (free)

Tabby is a free tab manager for Chrome and Firefox that keeps saved tabs on your new tab page, organized and searchable, with no account.

  1. Install Tabby. Add Tabby from the Chrome Web Store (free, no account) and open a new tab.
  2. Click Save window. On Tabby's home, under Open tabs, click Save window. Every tab in the window goes into a new collection; a page open twice is saved once.
  3. Close the tabs. Click Close the tabs in the message that appears. The tabs close; the collection stays on your new tab page.
  4. Open them again later. Open the collection and click Open all, or find one link with ⌘K.

Good for: closing tabs every day without losing them. Tabby also brings back a window you closed by mistake (for 14 days) and can tidy up open tabs one key at a time.

Using Firefox?

Firefox has the same built-in option: right-click any tab, choose Select All Tabs, then right-click again and choose Bookmark Tabs…. In most versions Ctrl+Shift+D (⌘+Shift+D on a Mac) does the same. Menu names can differ between Firefox versions. Tabby for Firefox (Firefox 140+) works just like the Chrome steps above.

Questions

What is the shortcut to save all tabs in Chrome?

Press Ctrl+Shift+D on Windows, Linux and ChromeOS, or ⌘+Shift+D on a Mac. Chrome asks for a folder name and bookmarks every tab in the window into it.

Can Chrome reopen my tabs after a restart?

Yes. In Settings → On startup choose “Continue where you left off”. This reopens the last session, but it is not a saved copy: close a window and those tabs are gone from it.

How do I save tabs and close them without bookmarks?

Use a tab manager. In Tabby, click Save window on the new tab page: every tab goes into a new collection, then one click closes them. Bring them back any time from Tabby's home or with ⌘K search.
