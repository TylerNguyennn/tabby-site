How to install Tabby (Chrome, Edge, Brave, Firefox)

Install Tabby from the Chrome Web Store, pin its icon, keep it as your new tab, and find your way around, step by step.

Step by step

What you’ll do

  1. Install Tabby, pin its icon, and have it open on every new tab.
  2. On Tabby’s Chrome Web Store page, click Add to Chrome, then confirm with Add extension (Edge and Brave use the same store; Firefox uses addons.mozilla.org).

Pin the icon

  1. In the browser toolbar, at the top right, click the puzzle piece.
  2. Click the pin next to Tabby, so Tabby’s icon always shows in the toolbar.

First start

  1. Open a new tab with ⌘T / Ctrl+T; Tabby now opens on every new tab.
  2. If Chrome asks Change back to Google?, click Keep it.
  3. Type your name if you like, pick a look such as Graphite, and click Continue.
  4. Click Set me up, untick any suggested space you don’t use, and click Add 3 spaces.
  5. Click I'll explore on my own (the tour can be replayed from Settings), then click Open Tabby.

Find your way

  1. On Home, below the Get started card, Open tabs lists every tab you have open.
  2. In the sidebar on the left, Later is your read-later list.
  3. Under Spaces in the sidebar are the spaces that hold your saved pages, such as Work or Shopping.
  4. In the sidebar, Search finds anything.

Good to know

  • Edge and Brave: install from the Chrome Web Store the same way. Firefox: addons.mozilla.org.
  • The 1-minute practice tour (Show me) can be replayed any time from Settings.
