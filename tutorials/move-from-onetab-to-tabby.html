How to export OneTab tabs and import them into Tabby

Copy OneTab’s list into a plain text file, then import it in Tabby’s Settings: 3 groups and 15 links become 3 collections.

Step by step

What you’ll do

Copy your OneTab list into a plain text file, then import it so each OneTab group becomes a Tabby collection.

Save it as a text file

  1. In OneTab, at the top right, click Export / Import URLs.
  2. Select the whole list and copy it: ⌘A, then ⌘C (Ctrl+A, then Ctrl+C on Windows).
  3. Open TextEdit on a Mac and choose Format → Make Plain Text; on Windows, open Notepad.
  4. Paste the list with ⌘V / Ctrl+V.
  5. Save with ⌘S / Ctrl+S, name the file onetab, keep Downloads, and click Save.

Import into Tabby

  1. Open a new tab and, at the bottom of Tabby’s sidebar, click Settings.
  2. Scroll down to Your data.
  3. In the Import section, click Choose file…, pick the onetab file in Downloads, and click Open.
  4. Check what Tabby found (in the video, 3 collections and 15 links) and click Import.

Your new space

  1. Each OneTab group is now a collection in a new space called Imported from OneTab.
  2. Rename the collections any time.

Good to know

  • On Windows, paste the list into Notepad and save it as a .txt file.
  • Each OneTab group becomes a collection in a new space; rename them any time.
